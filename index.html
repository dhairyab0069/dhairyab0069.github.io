Genesis cartridge rack

Projects should insert like media.

Instead of bland cards, each project becomes a labeled cartridge. That is closer to the Genesis philosophy: discrete modules, visible identity, tactile selection, and a sense that each project is a machine you plug in and run.

Embedded + LLM

CACTILab: a 4-stage pipeline (Claude + OpenHands SDK) that parses MCU datasheets, runs TDD red-phase verification, generates no_std Rust HAL crates, and self-validates via compiler-in-the-loop feedback. First milestone: 128 passing cargo tests, 73 GPIO pins, MSPM0L2228.

Rust systems

Project Escalion: building a custom game engine in Rust from the ground up at NU Launch Labs. Focus on memory architecture, performance-critical subsystems, and zero-cost abstractions. Also: MITRE eCTF 2026 participant — embedded security firmware in a competition context.
